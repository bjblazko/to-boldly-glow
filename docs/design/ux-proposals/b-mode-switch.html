B: Mode Switch

Idea: keep today's dock, but split the app into two modes with a switch at the top: Explore and Learn. Each mode has its own dock, so neither is crowded. Explore's dock is Find · Camera · Time · View. Learn opens a lesson library first, then a lesson dock. A command palette (Ctrl+K / 🔍) searches objects, lessons and settings in one list. Graphics move behind ⚙.
