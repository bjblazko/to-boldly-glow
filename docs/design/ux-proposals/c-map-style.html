C: Map Style

Idea: work like Google Maps, but for space. A search box top-left is the main way in. It opens a categorized tree of objects and matching lessons. Picking something opens a card with its actions. Everything else is a few floating buttons: Layers (what is shown) top-right, zoom / tilt / reset bottom-right, and a timeline along the bottom. Graphics settings sit at the foot of the Layers popover ("Graphics…"), out of the way. There is no dock.

Notes

  • + The least chrome: one search box, a few floating buttons, the scene everywhere else. A familiar pattern (maps).
